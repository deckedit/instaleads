# InstaLeads — Premium Landing Page

Landing page statis untuk jasa **Mencari Calon Pelanggan dari Instagram**.

## Paket
- **Starter Rp99K** — 1 target campaign, hingga 1.000 username Instagram, data terstruktur, export CSV/Excel.
- **Konsultasi Custom** — kebutuhan di atas paket Starter diarahkan ke konsultasi.

## Ganti nomor WhatsApp
Buka `script.js` lalu ubah:
`const whatsappNumber = "628XXXXXXXXXX";`

## Publish ke GitHub Pages
Upload seluruh isi folder ke repository, termasuk folder `assets`, lalu:
**Settings → Pages → Deploy from a branch → main → /(root) → Save**.
